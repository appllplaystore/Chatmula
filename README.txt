ChatMula GitHub Pages — root-files edition

Upload every file in this folder directly into the ROOT of your GitHub repository. Do not create an assets folder. All images are referenced by filename, e.g. ./icon.jpg and ./bot_alex_carter.jpg. Keep all filenames unchanged.

Required root files include index.html, manifest.json, sw.js, icon.jpg, icon-192.png, icon-512.png, and all bot_*.jpg images.

GitHub Pages is static hosting. The app uses its configured Supabase project for backend actions; verify backend functions and payment flows separately before production use.
